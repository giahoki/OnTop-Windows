# OnTop Windows

Простая утилита, которая показывает любое окно поверх всех остальных в виде живого эскиза-клона. Удобно для просмотра видео во время работы, мониторинга фоновых процессов или держания справочных окон на виду.

Сделано на чистом Win32 API и DWM Thumbnails — легко, без зависимостей, один .exe.

> 🇺🇸 [English README](README.md)

---

## Возможности

- Живой DWM-клон любого окна поверх всех
- Режим обрезки — показ только части исходного окна
- Ресайз клона: **Alt** + Колёсико (медленно) / **Alt+Shift** + Колёсико (быстро)
- Игнорирование кликов (**Alt+Shift+O**) — окно становится некликабельным
- Настраиваемая скорость ресайза и горячие клавиши
- Проверка обновлений
- 7 языков интерфейса: Русский, English, Español, Українська, Français, Deutsch, Polski

## Использование

1. Запустите — появится небольшое окно
2. Нажмите **Select Window**, выберите окно из списка
3. Откроется живой клон поверх всех окон

- **Перемещение**: перетащите за заголовок
- **Сброс клона**: ПКМ → Reset Window
- **Границы**: ПКМ → Borders
- **Настройки** ⚙ — биндинги, язык, авто-обновление

## Требования

- Windows 7+

## Сборка

Откройте `ontopwindows.slnx` в Visual Studio 2022+, сборка **Release/x64**.
